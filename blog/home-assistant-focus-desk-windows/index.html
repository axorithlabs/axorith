Home Assistant

Connect your Windows focus routine to Home Assistant

Let a work preset mark the change in your room as well as on your desktop.

Download for WindowsGitHub

The beginning of a work session is an environmental change: apps open, distractions close and the desk should be ready. With the optional Home Assistant module, Axorith can attach configured device actions to that same start or end boundary without turning the entire desktop workflow into a cloud service.

Start with one simple room action

Choose a light or scene in Home Assistant that helps distinguish work time from leisure. Configure that action with the Home Assistant module in your Axorith preset. Keep the first version small and test it while you can still operate the device normally; a complex chain of device automations makes failures harder to diagnose.

Keep the digital steps together

In the same preset, Application Launcher can prepare your editor or browser while App Blocker and Site Blocker apply the selected restrictions. This makes the room action one piece of a larger context change. Home Assistant does not need to decide which Windows applications you should open.

Plan a sensible end state

Decide whether the preset should restore a neutral scene or trigger a different one when the session ends. Avoid assuming every session ends normally: power loss, device connectivity and a stopped service can interrupt automation. Keep physical controls and Home Assistant available as the fallback.

Use it only if the feedback helps

An indicator light can reinforce a routine, but it is optional. If it becomes another configuration chore, keep the Windows preset and omit the room automation. The benefit comes from fewer manual transitions, not from adding devices for their own sake.
