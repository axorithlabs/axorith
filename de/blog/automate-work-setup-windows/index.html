Arbeitsbereich automatisieren

Windows-Arbeitsumgebung automatisieren

Mache aus wiederholter Vorbereitung für Arbeit, Lernen oder Programmieren ein selbstständig startendes Profil.

Für Windows herunterladen GitHub

Eine wiederholbare Windows-Arbeitsumgebung startet mehr als Apps. Sie schließt oder blockiert Ablenkungen, öffnet das richtige Projekt, setzt Sitzungsregeln um und weiß, wann der Arbeitsbereich enden soll. Axorith speichert das als Profil.

Vor Axorith

Jeden Tag dieselbe Vorbereitung.

IDE öffnen. Projekt suchen. Browser öffnen. Steam und Discord schließen. Passende Musik und Blocker starten. Mit Home Assistant auch die Raumszene einstellen. Jeder Schritt ist einfach, zusammen werden sie bei jedem Kontextwechsel zum Ritual.

Profil

Beschreibe den gewünschten Zustand einmal.

Ein Profil kann App-Starter, App- und Website-Blocker sowie optionale Module wie Spotify oder Home Assistant enthalten. Es speichert auch Sitzungsregeln, darunter Schutz vor vorzeitigem Beenden und Stoppbedingungen.

Zeitplanung

Vom App-Starter zum festen Ablauf.

Zeitplanung macht aus einem Knopf einen Ablauf. Programmieren kann werktags um 09:00 starten, um 18:00 enden und an Entspannen übergeben. Das zweite Profil kann andere Apps mit anderen Blockierregeln starten.

Der Zeitplan gehört zur Definition des Arbeitsbereichs. Kein separates Aufgabenplaner-Skript muss mit den Blockierregeln synchron gehalten werden.

Sitzungsschutz

Entscheide, wie leicht sich die Sitzung abbrechen lässt.

Manche Sitzungen brauchen nur Struktur, andere stärkeren Schutz. Axorith hält diese Regeln im Profil fest: wie die Sitzung endet, ob Pausen möglich sind und was danach passiert.

Home Assistant

Der Raum kann dem Arbeitsbereich folgen.

Das Home-Assistant-Modul kann konfigurierte Entitäten beim Start und Ende der Sitzung auslösen. So folgen Schreibtischlicht und Szenen dem digitalen Arbeitsbereich, während der Rest von Axorith lokal bleibt.
