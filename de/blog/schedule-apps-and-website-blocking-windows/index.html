Windows-Zeitplanung

App-Start und Ablenkungssperren unter Windows planen

Ein Zeitplan für die gesamte Sitzung statt einzelner Aufgaben für Starter und Blocker.

Für Windows herunterladen GitHub

Der Windows-Aufgabenplaner startet Programme zu einer Uhrzeit. Ein Blocker sperrt ablenkende Apps und Websites. Axorith verbindet beides in einem geplanten Arbeitsbereich: Startzeit, Starter, Blocker und Stoppregel gehören zur selben Sitzung.

Beispiel

Programmieren um 09:00 starten, um 18:00 beenden.

09:00Programmieren beginnt

IDE und Browser starten, App- und Website-Blocker anwenden und konfigurierte Sitzungsregeln aktivieren.

18:00Programmieren endet

Sitzung zu fester Zeit beenden und optional das nächste Profil starten.

Wiederkehrende Starts

Zeitplan mit dem Profil verbinden.

Wiederkehrende Starts lassen sich auf ausgewählte Tage wie Montag bis Freitag begrenzen. So beschreibt der Zeitplan den Beginn des ganzen Arbeitsbereichs statt nur den Start einer EXE.

Stoppregeln

Nach Uhrzeit oder Dauer beenden.

Nutze für einen festen Ablauf eine Stoppzeit. Soll die Sitzung unabhängig vom Startzeitpunkt gleich lange dauern, nutze eine Dauer. Ein Profil kann nach natürlichem Abschluss den nächsten Arbeitsbereich festlegen.

Warum nicht nur der Aufgabenplaner?

Der Aufgabenplaner startet einen Prozess, verwaltet aber keinen Arbeitsbereichszustand.

Die Windows-Zeitplanung eignet sich zum Start einer ausführbaren Datei. Mit Blockern, mehreren Apps, Projektpfaden, Sitzungsschutz und Folgeaktion wird die Pflege aufwendiger. Axorith vereint diese Teile in einem Profil statt in verstreuten Skripten und Hilfsprogrammen.
