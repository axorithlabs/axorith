Entorno de concentración Windows

Bloquea aplicaciones y sitios y abre tu entorno de trabajo en Windows

Una configuración elimina distracciones y prepara el espacio que las sustituye.

Descargar para Windows GitHub

Axorith reúne tres tareas normalmente separadas en Windows: bloquear aplicaciones, bloquear sitios y abrir las aplicaciones o proyectos útiles. Todo queda en una configuración para empezar a trabajar con una acción.

Funciona de forma local y se centra en Windows. El uso personal y no comercial es gratuito con BSL 1.1.

El problema

El bloqueador es solo la mitad del trabajo.

Prepararse para concentrarse suele implicar acciones aisladas: cerrar Discord o Steam, abrir un IDE, el perfil de navegador o proyecto correcto, poner música y activar el bloqueador. El bloqueador elimina distracciones, pero normalmente no prepara el entorno que las sustituye.

Axorith trata todo el entorno como una sesión. La configuración define qué debe estar disponible y qué debe desaparecer mientras esté activa.

Una configuración

Abre el espacio y aplica las restricciones a la vez.

01

Abre aplicaciones de trabajo

Abre aplicaciones, proyectos de IDE y configuraciones de navegador al empezar la sesión.

02

Bloquea distracciones del escritorio

Bloquea aplicaciones seleccionadas o permite solo las del espacio actual.

03

Bloquea sitios que distraen

Aplica reglas de sitios y bloqueo por categorías durante la sesión.

04

Termina según tus reglas

Detén manualmente, tras una duración, a una hora fija o pasa a otra configuración.

Lanzador de aplicaciones

Abre lo que hace que ese tiempo sea útil.

El lanzador abre aplicaciones y proyectos de IDE como parte de la configuración. También gestiona ventanas y ciclo de vida, sin limitarse a abrir un EXE. El espacio deseado aparece cuando desaparecen las distracciones.

Planificación

Inicia manualmente o a una hora fija.

La configuración puede ser manual o programada. Puede empezar de lunes a viernes a las 09:00, detenerse a una hora fija o tras una duración y abrir otra configuración, como Descanso.

Esa es la diferencia entre utilidades aisladas y una regla de espacio: los lanzadores, bloqueadores y condición de finalización comparten el ciclo de sesión.

Alcance

Lo que Axorith no pretende sustituir.

Axorith es actualmente una herramienta de escritorio Windows. Si buscas sobre todo bloqueo sincronizado entre móviles, tabletas y ordenadores, un producto como Freedom encaja mejor. Axorith gestiona el espacio: qué se abre, qué se bloquea, cuánto dura la sesión y qué viene después.
