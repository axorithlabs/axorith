Horarios Windows

Programa la apertura de aplicaciones y el bloqueo de distracciones en Windows

Un horario para toda la sesión en lugar de tareas separadas para lanzadores y bloqueadores.

Descargar para Windows GitHub

El Programador de Windows abre un programa a una hora. Un bloqueador impide el acceso a distracciones. Axorith combina estas acciones en un espacio programado donde horario, lanzadores, bloqueadores y parada pertenecen a la misma sesión.

Ejemplo

Empieza Programación a las 09:00 y termina a las 18:00.

09:00Empieza Programación

Abre IDE y navegador, aplica bloqueos e inicia las reglas configuradas de la sesión.

18:00Termina Programación

Termina la sesión a la hora fija y, si quieres, inicia la siguiente configuración.

Inicios recurrentes

Vincula el horario a la configuración.

El inicio recurrente puede limitarse a días concretos, como de lunes a viernes. El horario define cuándo empieza todo el espacio, no solo un EXE.

Reglas de parada

Termina por hora o por duración.

Para una rutina fija, define una hora de finalización. Si la sesión debe durar lo mismo independientemente de cuándo empiece, establece una duración. La configuración también puede indicar qué espacio de trabajo iniciar después de una finalización normal.

¿Por qué no basta con el Programador de tareas?

El Programador de tareas inicia un proceso, pero no gestiona el estado del espacio de trabajo.

El planificador de Windows sirve para ejecutar un archivo. Mantener la rutina es más difícil si incluye bloqueadores, varias aplicaciones, rutas de proyectos, protección y transición final. Axorith lo reúne en una configuración en vez de scripts y utilidades dispersos.

AXORITH PARA WINDOWS

Inicia el entorno en vez de reconstruirlo.

Crea el espacio una vez y ábrelo manualmente o deja que lo haga el horario.
