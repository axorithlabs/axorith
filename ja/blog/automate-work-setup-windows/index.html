ワークスペースの自動化

Windowsの作業環境を自動化

仕事、学習、コーディングのたびに繰り返す準備を、自動で動くプリセットに変えましょう。

Windows版をダウンロード GitHub

再現できるWindowsの作業環境には、アプリを開く以上の役割があります。気が散るものを閉じる・ブロックする、正しいプロジェクトを開く、セッションのルールを適用する、終了時刻を管理する。Axorithはこれらをプリセットに保存します。

Axorith導入前

同じ準備を毎日繰り返していませんか。

IDEを開き、プロジェクトを探し、ブラウザーを起動。SteamとDiscordを閉じ、音楽とブロックを開始。Home Assistantを使うなら部屋のシーンも設定。ひとつずつは簡単でも、作業を切り替えるたびに同じ準備を繰り返すことになります。

プリセット

必要な状態を一度定義する。

プリセットにはアプリの起動、アプリとサイトのブロック、SpotifyやHome Assistantなどのオプションモジュールを含められます。途中終了を防ぐセッション保護や停止条件など、セッション自体のルールも保存します。

スケジューラー

アプリの起動から、本当の習慣へ。

予約により、プリセットは単なるボタンから習慣に変わります。たとえば平日09:00にプログラミングを開始し、18:00に終了してリラックスへ切り替えられます。次のプリセットは別のアプリやブロックルールを使えます。

スケジュールはワークスペースの定義の一部です。ブロック設定と別のタスクスケジューラー用スクリプトを同期させる必要はありません。

セッション保護

セッションを途中で終了できる条件を設定します。

構造だけが必要なセッションもあれば、強い保護が必要なものもあります。Axorithは終了方法、休憩の有無、完了後の動作をプリセットにまとめます。

Home Assistant

作業環境に合わせて室内の機器も切り替えられます。

Home Assistantモジュールはセッションの開始・終了時に設定済みのエンティティを動かせます。デスクライトやシーンをデジタルな作業環境と連動させつつ、Axorithのほかの機能はローカルで動作します。
