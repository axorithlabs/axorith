Windowsのスケジュール

Windowsでアプリの起動と集中を妨げるもののブロックを予約

起動ツールとブロッカーを別々に予約せず、セッション全体をひとつのスケジュールに。

Windows版をダウンロード GitHub

Windowsのタスクスケジューラは指定時刻にプログラムを起動し、ブロッカーはアプリやサイトへのアクセスを制限します。Axorithはこれらを予約済みの作業環境にまとめ、開始時刻、起動対象、ブロック、終了ルールを同じセッションで管理します。

例

09:00にプログラミング開始、18:00に終了。

09:00プログラミング開始

IDEとブラウザーを起動し、アプリとサイトのブロックを適用して、設定済みのセッションルールを有効にします。

18:00プログラミング終了

指定時刻にセッションを終了し、必要なら次のプリセットを開始します。

繰り返し開始

プリセットにスケジュールを設定。

繰り返し開始を月〜金など指定の曜日に限定できます。スケジュールはEXEひとつの起動ではなく、ワークスペース全体の開始を定義します。

終了ルール

指定時刻または経過時間で終了。

固定の習慣には終了時刻を使います。開始時刻に関係なく同じ長さのセッションには継続時間を指定します。正常に完了した後に起動する次のワークスペースも設定できます。

タスクスケジューラだけではだめ？

タスクスケジューラはプロセスを起動しますが、作業環境の状態は管理しません。

Windows標準の予約は、実行ファイルを動かすだけなら便利です。ブロック、複数アプリ、プロジェクトのパス、セッション保護、終了後の切り替えまであると管理が複雑になります。Axorithはスクリプトやツールに分散させず、プリセットにまとめます。
