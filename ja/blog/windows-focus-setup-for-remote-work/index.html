在宅勤務

Windowsの在宅勤務で集中環境を整える

必要な連絡手段を残しながら、仕事に関係のない中断を減らします。

Windows版をダウンロードGitHub

リモートワークでは会議、チャット、ブラウザーと本来の作業が同じPC上にあります。すべての連絡ツールを閉じるのではなく、必要な連絡と無関係な誘惑を区別し、作業を切り替えやすくすることが大切です。

集中作業と会議を分ける

現在のプロジェクトに必要なエディター、文書、ウェブサイトをプリセットへ登録します。仕事で常時連絡が必要なら通話やメッセージを残しましょう。共同作業には別の制限の少ないプリセットを用意できます。

予定は助けになる形で使う

繰り返しの開始時刻で環境を準備し、終了時刻で区切りを作れます。ただし突発的な会議や緊急対応では手動開始の方が適切です。スケジュールは仕事を妨げるものにしないでください。

重要な通知と権限を確認する

強いブロックの前に会議リンク、ログイン画面、画面共有、本人確認アプリを試します。厳しすぎる許可リストは本来の業務を止める場合があります。緊急の対応手段を確保しましょう。

一日の終わりを自分で決める

休憩用のプリセットは仕事との境界を作りますが、未返信のメッセージを送ったりファイルを保存したりはしません。先に必要な作業を済ませます。自動化は繰り返しを減らすもので、大切な判断の代わりにはなりません。
