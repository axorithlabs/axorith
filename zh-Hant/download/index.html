Windows

下載 Axorith。

一個本機組合可以啟動所需程式、封鎖不需要的程式與網站，並依排程執行。

下載 axorith-setup.exe 版本資訊

原始碼依 BSL 1.1 授權公開，個人及非商業使用免費。

01

本機服務

Axorith 的專注時段邏輯在你的 Windows 電腦執行。介面與背景 Host 分開，因此活動專注時段不依賴持續開啟的視窗。

02

直接下載安裝程式

按鈕直接下載官方 GitHub 發行版本中的最新 Windows 安裝程式，不需要電子郵件或帳號。

03

原始碼可檢視

程式碼儲存庫公開，包含桌面程式、模組與安裝程式。安裝前可檢視程式碼或 BSL 1.1 授權條款。
