Windows 排程

在 Windows 定時啟動程式並封鎖干擾

用一個排程管理整個專注時段，不必分別安排啟動器與封鎖工具。

下載 Windows 版 GitHub

Windows 工作排程器能在指定時間執行程式，封鎖工具能限制干擾程式或網站。Axorith 將它們整合為排程工作區，讓開始時間、啟動器、封鎖與停止規則屬於同一個專注時段。

範例

09:00 開始程式設計，18:00 結束。

09:00程式設計開始

啟動 IDE 與瀏覽器、套用程式與網站封鎖，並執行已設定的專注時段規則。

18:00程式設計結束

在指定時間結束專注時段，並可選擇啟動下一個組合。

重複啟動

將排程附加至組合。

重複啟動可以限定在選定日期，例如週一至週五。排程定義整個工作區何時開始，而不只是一個 EXE 何時啟動。

停止規則

依時間或長度結束。

固定作息可使用指定停止時間；如果希望不論何時開始都持續相同長度，則使用持續時間。組合還可指定正常完成後啟動的下一個工作區。

為什麼不只用工作排程器？

工作排程器能啟動處理程序，但不管理工作區狀態。

Windows 原生排程適合「執行這個程式」。但需要封鎖、多個程式、專案路徑、專注時段保護及結束後銜接時，維護會變複雜。Axorith 將內容集中在組合，而非分散在指令碼和工具中。

WINDOWS 版 AXORITH

直接啟動環境，不必從頭建立。

工作區只需建立一次，之後手動啟動或交給排程執行。
