應用程式封鎖

如何在 Windows 上只允許運行工作應用

先確定工作真正需要哪些應用，而不是試圖列出每一種可能分散注意力的程式。

下載 Windows 版GitHub

普通黑名單要求你預先找出所有干擾來源。白名單則反過來：先確定完成任務需要的軟體，再限制其他程式。它適合工具明確、但難以預測下一次分心會來自哪裡的工作。

先列出真正需要的軟體

建立“編程”預設，在 Application Launcher 中加入編輯器、專案和工作瀏覽器。別忘了終端、密碼管理器或必要的通信工具。遺漏這些程式的嚴格白名單可能妨礙工作，而不是幫助專注。

通過 App Blocker 應用規則

App Blocker 可以只允許當前 Workspace 中配置的應用。將啓動器和封鎖器放進同一個預設，工作環境和限制便能隨專注時段一起啓動。這是針對特定工作專注時段的設置，並非永久修改 Windows。

啓用嚴格模式前先測試

先運行一個容易停止的短專注時段，檢查文件選擇器、建置工具、重要消息和輔助功能軟體。確認所有必需程式可用，再提高 Focus Commitment 的嚴格程度。不要阻斷重要的安全操作或恢復途徑。

甚麼時候黑名單更合適

如果工作經常需要臨時打開未知程式，白名單可能太嚴格。此時只封鎖游戲或聊天軟體等已知干擾即可。應用啓動與日程設置可以保持不變，只調整 App Blocker 的策略。
