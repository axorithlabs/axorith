Windows 專注環境

封鎖程式與網站，再啟動 Windows 工作環境

一個組合既移除干擾，也建立取代它們的工作區。

下載 Windows 版 GitHub

Axorith 將通常分散在不同 Windows 工具中的三件事結合：封鎖桌面程式、封鎖網站，以及啟動真正需要的程式或專案。設定都在一個組合中，讓開工變成一次操作。

優先於本機執行，目前圍繞 Windows 桌面設計。依 BSL 1.1 授權，個人及非商業使用免費。

問題

封鎖只是工作流程的一半。

專注前往往要完成多個獨立操作：關閉 Discord 或 Steam、開啟 IDE、正確的瀏覽器設定檔或專案、播放音樂，再啟用網站封鎖。封鎖工具能移除干擾，卻通常不會建立取代它們的工作環境。

Axorith 將整個環境視為一個專注時段。組合同時定義哪些內容保持可用，哪些應在專注時段中消失。

一個組合

同時啟動工作區並套用限制。

01

開啟工作程式

專注時段開始時啟動程式、IDE 專案與瀏覽器設定。

02

封鎖桌面干擾

封鎖選定程式，或僅允許目前工作區中設定的程式。

03

封鎖干擾網站

專注時段期間套用網站規則與類別封鎖。

04

依你的規則結束

手動停止、於指定時間後或指定時刻結束，或銜接另一個組合。

應用程式啟動器

開啟讓專注時間更有價值的工具。

程式啟動模組可作為組合的一部分開啟應用程式與 IDE 專案，也支援視窗和生命週期設定，不只是「開啟這個 EXE」。目標是在移除干擾的同時，準備好需要的工作環境。

定時執行

手動啟動，或依指定時間執行。

組合可手動或依排程執行。例如週一至週五 09:00 開始，在指定時間或經過一定時間後停止，再啟動「休息」等另一個組合。

這就是一組獨立工具與統一工作區規則的差別：啟動、封鎖與結束條件共享同一個專注時段生命週期。

適用範圍

Axorith 不打算取代什麼。

Axorith 目前面向 Windows 桌面。如果主要需求是在手機、平板與電腦間同步封鎖，Freedom 這類跨裝置產品更適合。Axorith 關注工作區本身：啟動什麼、封鎖什麼、專注時段持續多久、結束後做什麼。
