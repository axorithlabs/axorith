學習流程

如何在 Windows 上安排少干擾的學習專注時段

保留完成作業需要的工具，減少無關內容的干擾。

下載 Windows 版GitHub

學習可能需要 PDF、筆記、瀏覽器、計算器或視頻課程。因此一開始就封鎖整個互聯網通常並不合理。更好的方法是區分學習資源和無關瀏覽，並設定現實可行的學習時間。

準備當前作業需要的環境

建立“學習”預設，加入筆記應用、參考資料和瀏覽器。如果作業需要學校網站，確保該網站能打開。準備好實際材料，比啓動一個沒有學習內容的空泛“學習模式”更有用。

封鎖娛樂而不是課程

使用 Site Blocker 限制無關社交、購物及娛樂網站，App Blocker 則處理桌面干擾。注意課程服務是否與被封鎖的網站類別重合。提前收緊規則範圍，比上課途中突然打不開網頁好得多。

選擇能夠完成的時長

根據作業設定專注時段時間，並考慮是否需要休息。Focus Commitment 可隨預設配置，但並非必須使用嚴格模式。最好從短專注時段開始，確保學習材料始終可用。

復盤真正的中斷原因

結束後檢查問題來自被封鎖的資源、遺漏的文件，還是無關程式。先修正預設，不要默認增加限制。目標是減少準備時間，把精力留給學習本身。
