Home Assistant

將 Windows 專注模式連接到 Home Assistant

讓工作預設同時調整桌面應用與房間環境。

下載 Windows 版GitHub

工作開始意味著環境變化：工具打開、干擾減少、桌面準備就緒。借助可選的 Home Assistant 模塊，Axorith 可以把設備動作與預設的開始或結束連接起來，無須把整個桌面工作流程轉移到雲端。

從一個簡單設備動作開始

在 Home Assistant 中選擇代表工作狀態的燈光或場景，然後在 Axorith 預設中配置對應操作。先測試簡單方案，並確保仍能正常手動控制設備。複雜的自動化鏈更難排查故障。

將數字環境一並準備好

同一個預設里，Application Launcher 可打開編輯器或瀏覽器，App Blocker 與 Site Blocker 則應用選定規則。房間動作只是環境切換的一部分；Home Assistant 不需要負責管理 Windows 應用。

計劃結束後的狀態

決定專注時段結束時恢復普通燈光，還是觸發另一個場景。不要假設每次都正常結束：斷電、網絡或設備連接問題可能中斷自動化。保留實體開關等後備控制方式。

只保留真正有用的動作

燈光提示可以強化工作與休息的邊界，但並非必需。如果設置本身變成負擔，保留 Windows 預設即可。價值在於減少手動切換，而不是增加設備數量。
