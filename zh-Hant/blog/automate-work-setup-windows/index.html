工作區自動化

自動化你的 Windows 工作環境

將工作、學習或寫程式前的重複準備，變成能自行執行的組合。

下載 Windows 版 GitHub

可重複使用的 Windows 工作環境不只是啟動程式，還要關閉或封鎖干擾、開啟正確專案、執行專注時段規則，並決定工作區何時結束。Axorith 將這些內容儲存為組合。

使用 Axorith 之前

同樣的準備，每天都在重複。

開啟 IDE、尋找專案、啟動瀏覽器、關閉 Steam 和 Discord、播放音樂、開啟封鎖。如果使用 Home Assistant，還要設定房間情境。每一步都不難，但每次切換任務都得重複，就成了繁瑣的準備儀式。

預設組合

只需定義一次所需狀態。

組合可包含程式啟動、程式封鎖、網站封鎖，以及 Spotify、Home Assistant 等選用模組，也儲存專注時段本身的規則，包括防止提早結束的保護及停止條件。

排程管理

從啟動器，變成真正的工作習慣。

排程讓組合從按鈕變成日常規則。例如平日 09:00 啟動「程式設計」，18:00 結束後交給「休息」。第二個組合可以啟動另一組程式，使用不同的封鎖規則。

排程屬於工作區定義的一部分，無須另外撰寫工作排程器指令碼，再與封鎖設定保持同步。

專注時段保護

決定中途退出專注時段的難易程度。

有些專注時段只需要安排，有些則需要更強的約束。Axorith 將結束方式、是否允許休息及完成後的操作，一併儲存在組合中。

Home Assistant

房間中的裝置也能隨工作區切換。

Home Assistant 模組可於專注時段開始或結束時觸發已設定的實體，讓桌燈或情境隨數位工作區同步切換，而 Axorith 其他功能仍於本機執行。

WINDOWS 版 AXORITH

直接啟動環境，不必從頭建立。

工作區只需建立一次，之後手動啟動或交給排程執行。
