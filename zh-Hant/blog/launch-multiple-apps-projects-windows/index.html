應用程式啟動器

如何在 Windows 上同時啓動工作應用和專案

偶爾打開一組工具很簡單；每天重復同樣的步驟才浪費時間。

下載 Windows 版GitHub

工作日可能總要打開相同的編輯器、倉庫、瀏覽器和輔助程式。啓動器能減少這些點擊。Axorith 還將啓動流程存放在預設中，並可同時配置干擾封鎖和專注時段時長。

列出屬於同一任務的工具

先從 IDE、專案、瀏覽器開始，必要時再加終端或筆記。不要為了“以防萬一”打開一大堆程式。好的預設應讓接下來的任務更清楚，而不是把桌面堆滿窗口。

通過 Application Launcher 進行配置

該模塊可啓動應用和 IDE 專案，並提供窗口位置與生命週期選項。把這些設置放進預設，與其他模塊一起啓動。移動倉庫或重新安裝軟體之後要檢查路徑；錯誤路徑會導致啓動失敗。

只在需要時添加封鎖

同一預設可以包含 App Blocker 與 Site Blocker，但不是每種工作都需要。研究任務可能適合較自由的環境，寫作則可能需要限制游戲和社交網站。沒必要讓所有工作環境都變成嚴格鎖定的專注時段。

追求可重復而不是複雜

測試預設後，可以手動運行或按日程啓動。遇到問題先修正具體原因，不要馬上增加更多自動動作。真正的價值在於每天都能可靠地進入工作狀態。
