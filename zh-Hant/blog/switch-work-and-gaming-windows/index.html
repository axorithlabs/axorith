工作環境切換

如何在 Windows 上切換工作和游戲環境

工作與休閒不必共用同一組窗口、通知和限制。

下載 Windows 版GitHub

同一台電腦很容易混用環境：工作時游戲啓動器與 Discord 還開著，休息時 IDE 和專案窗口又擋在眼前。獨立預設能夠明確每個環境應該是甚麼樣子，減少手動整理。

為不同情境建立獨立預設

在“編程”預設中加入 IDE、瀏覽器和工作封鎖規則；在“休閒”預設中加入游戲、聊天和音樂，不使用工作限制。不要把所有程式都複製到兩個預設里，否則就失去了切換的意義。

選擇切換方式

Axorith 可以手動啓動預設、按日程啓動，或在前一個預設結束後啓動。比如工作到指定時間，再切換到休閒。如果每天的安排不固定，手動切換可能比突然自動轉換更合適。

不要依賴工具替你保存工作

切換環境不能代替保存文件、提交代碼或安全結束重要進程。先用非關鍵程式測試 Application Launcher 的生命週期選項。預設無法判斷未保存的內容是否可以丟棄。

把結束工作變成清晰的邊界

兩個預設的價值在於清楚地區分工作與休息。工作專注時段結束後，無須逐一手動關閉每項封鎖就能進入休閒。如果計劃有變，修改日程或手動切換即可。
