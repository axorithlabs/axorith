遙測與資料

Axorith 使用 PostHog 分析網站，並提供選用的桌面產品遙測。網站與桌面程式採用獨立訪客身分。

網站分析

造訪 axorith.com 時，PostHog Web SDK 記錄頁面瀏覽與離開、造訪工作階段、Web Vitals、來源類別，以及經驗證的 UTM 來源、媒介與活動標籤。頁面歸為首頁、模組、隱私等固定類別。傳送前移除完整頁面和來源 URL、網域、廣告點擊 ID、UTM 內容與搜尋詞。也會記錄下載和 GitHub 連結點擊。下載點擊包含按鈕位置與 Windows 平台，只有網站確知版本時才包含發行版本。PostHog 可能根據網路中繼資料推斷大致位置。 也會記錄所選頁面語言。

網站使用 PostHog 的瀏覽器身分。Axorith 不透過 IP 位址、user-agent 比對、指紋辨識或其他啟發式方式，將網站訪客與後續安裝關聯。

桌面遙測

使用遙測預設開啟，可在程式的隱私權設定中關閉。Client 與 Host 共享此設定。更新讀取已儲存的選擇，新安裝保留現有預設值。

啟用後，桌面程式傳送 Axorith 與系統版本、程式生命週期事件、組合與模組 ID 及內建模組類型、工作階段 ID 與生命週期、保護及休息設定、排程變更、修改的設定類別、更新與安裝結果及結構化錯誤詳情。在 Windows 上，程式、安裝程式與解除安裝程式共享 Windows 提供的化名裝置識別碼。Axorith 不將其存入檔案。它在程式重裝或刪除程式資料夾後仍會保留；依 Windows 身分來源，也可能在全新安裝 Windows 後保留。更新時若舊身分可用，移轉事件會包含新舊識別碼以關聯遙測。

錯誤事件包含例外類型、穩定指紋、子系統、操作、嚴重程度、已處理或致命狀態，以及數量受限且經過清理的方法名稱。重複錯誤會限制頻率並彙整。

桌面程式不傳送的資訊

桌面遙測不包含組合名稱、自訂模組或操作名稱、設定值、檔案或執行檔路徑、處理程序名稱、命令列引數、URL、網域、Home Assistant 實體 ID、存取權杖、機密資訊、原始例外訊息或完整堆疊追蹤。Axorith 不會將 IP 位址當成事件屬性傳送。PostHog 可能根據網路中繼資料推斷大致位置。

PostHog 與身分

網站與桌面事件傳送至同一個 Axorith PostHog 專案，但採用獨立身分。網站不使用桌面程式的裝置識別碼。
