Harmonogramy Windows

Zaplanuj uruchamianie aplikacji i blokowanie rozpraszaczy w Windows

Jeden harmonogram całej sesji zamiast osobnych zadań uruchamiania i blokowania.

Pobierz dla Windows GitHub

Harmonogram Windows uruchamia program o określonej porze. Blokada ogranicza dostęp do rozpraszających aplikacji i stron. Axorith łączy te działania w zaplanowany obszar, w którym start, aplikacje, blokady i reguła zakończenia należą do jednej sesji.

Przykład

Rozpocznij Programowanie o 09:00, zakończ o 18:00.

09:00Programowanie się zaczyna

Uruchom IDE i przeglądarkę, zastosuj blokady oraz skonfigurowane reguły sesji.

18:00Programowanie się kończy

Zakończ sesję o stałej porze i opcjonalnie uruchom kolejny profil.

Cykliczne uruchamianie

Przypisz harmonogram do profilu.

Cykliczny start można ograniczyć do wybranych dni, np. od poniedziałku do piątku. Harmonogram określa początek całego obszaru, a nie tylko uruchomienie jednego EXE.

Reguły zakończenia

Zakończ o określonej porze lub po ustalonym czasie.

Dla stałej rutyny wybierz godzinę zakończenia. Jeśli sesja ma trwać tyle samo niezależnie od startu, wybierz czas trwania. Profil może określić kolejny obszar po naturalnym zakończeniu.

Dlaczego nie sam Harmonogram zadań?

Harmonogram zadań uruchamia proces, ale nie zarządza stanem obszaru roboczego.

Harmonogram Windows nadaje się do uruchomienia pliku. Utrzymanie staje się trudniejsze przy blokadach, wielu aplikacjach, ścieżkach projektów, ochronie sesji i przekazaniu sterowania. Axorith zbiera te elementy w profilu zamiast rozpraszać je po skryptach i narzędziach.
