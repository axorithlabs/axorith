Windows

下载 Axorith。

一个本地预设可以启动所需应用、屏蔽不需要的应用和网站，并按计划运行。

下载 axorith-setup.exe 发行说明

源代码按 BSL 1.1 许可公开，个人及非商业使用免费。

01

本地服务

Axorith 的专注时段逻辑在你的 Windows 电脑上运行。界面与后台 Host 分开，因此活动专注时段不依赖一个保持打开的窗口。

02

直接下载安装程序

按钮直接下载官方 GitHub 发行版中的最新 Windows 安装程序，无需邮箱或账户。

03

源码可查看

代码仓库公开，包含桌面应用、模块及安装程序。安装前可查看代码或 BSL 1.1 许可证。
