对比

Windows 上的 Axorith 与 Freedom 对比

Freedom 关注跨设备屏蔽，Axorith 关注 Windows 工作区本身。

下载 Windows 版 GitHub

Freedom 和 Axorith 都能屏蔽 Windows 应用与网站，但关注范围不同。Freedom 通过账户同步多个设备的屏蔽。Axorith 在本地管理 Windows 工作区，将屏蔽、应用和项目启动、专注时段规则及可选的 Home Assistant 操作结合起来。

本次对比于 2026 年 10 月 4 日参照 Freedom 公开的 Windows 和方案文档核对。

何时选择 Freedom

干扰会随你转移到其他设备。

如果一个专注时段需要覆盖 Windows 电脑、手机、平板及其他支持的设备，Freedom 更适合。免费方案含应用与网站屏蔽；重复专注时段、预约启动及锁定模式属于 Premium。

何时选择 Axorith

你想自动化 Windows 工作区本身。

Axorith 围绕桌面工作设计。预设可启动应用和项目、控制屏蔽、安排专注时段，并定义结束后的操作。它不尝试将同一屏蔽同步到你的所有设备。
