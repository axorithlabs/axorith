Home Assistant

将 Windows 专注模式连接到 Home Assistant

让工作预设同时调整桌面应用与房间环境。

下载 Windows 版GitHub

工作开始意味着环境变化：工具打开、干扰减少、桌面准备就绪。借助可选的 Home Assistant 模块，Axorith 可以把设备动作与预设的开始或结束连接起来，无须把整个桌面工作流程转移到云端。

从一个简单设备动作开始

在 Home Assistant 中选择代表工作状态的灯光或场景，然后在 Axorith 预设中配置对应操作。先测试简单方案，并确保仍能正常手动控制设备。复杂的自动化链更难排查故障。

将数字环境一并准备好

同一个预设里，Application Launcher 可打开编辑器或浏览器，App Blocker 与 Site Blocker 则应用选定规则。房间动作只是环境切换的一部分；Home Assistant 不需要负责管理 Windows 应用。

计划结束后的状态

决定专注时段结束时恢复普通灯光，还是触发另一个场景。不要假设每次都正常结束：断电、网络或设备连接问题可能中断自动化。保留实体开关等后备控制方式。

只保留真正有用的动作

灯光提示可以强化工作与休息的边界，但并非必需。如果设置本身变成负担，保留 Windows 预设即可。价值在于减少手动切换，而不是增加设备数量。
