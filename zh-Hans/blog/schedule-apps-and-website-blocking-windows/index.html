Windows 计划

在 Windows 定时启动应用并屏蔽干扰

用一个计划管理整个工作专注时段，不必分别安排启动器和屏蔽工具。

下载 Windows 版 GitHub

Windows 任务计划程序能在指定时间运行应用，屏蔽工具能限制干扰应用或网站。Axorith 将它们整合为定时工作区，让开始时间、启动器、屏蔽和停止规则属于同一个专注时段。

示例

09:00 开始编程，18:00 结束。

09:00编程开始

启动 IDE 和浏览器，启用应用与网站屏蔽，并执行已配置的专注时段规则。

18:00编程结束

在指定时间结束专注时段，并可选择启动下一个预设。

重复启动

将计划附加到预设。

重复启动可以限定在选定日期，例如周一至周五。计划定义的是整个工作区何时开始，而不只是一个 EXE 何时启动。

停止规则

按时间或时长结束。

固定作息可使用指定停止时间；如果希望不论何时开始都持续相同时长，则使用持续时间。预设还可指定正常完成后启动的下一个工作区。

为什么不只用任务计划程序？

任务计划程序能启动进程，但不管理工作区状态。

Windows 原生计划适合“运行这个可执行文件”。但需要屏蔽、多个应用、项目路径、专注时段保护和结束后衔接时，维护会变复杂。Axorith 将这些内容集中在预设中，而不是分散在脚本和工具中。
