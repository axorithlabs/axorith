工作区自动化

自动化你的 Windows 工作环境

将工作、学习或编程前的重复准备，变成能自行运行的预设。

下载 Windows 版 GitHub

可重复使用的 Windows 工作环境不仅是启动应用，还要关闭或屏蔽干扰、打开正确项目、执行专注时段规则，并确定工作区何时结束。Axorith 将这些内容保存为预设。

使用 Axorith 之前

同样的准备，每天都在重复。

打开 IDE、寻找项目、启动浏览器、关闭 Steam 和 Discord、播放音乐、开启屏蔽。如果使用 Home Assistant，还要设置房间场景。每一步都不难，但每次切换任务都要重复，就成了繁琐的准备仪式。

预设

只需定义一次所需状态。

预设可包含应用启动、应用屏蔽、网站屏蔽，以及 Spotify、Home Assistant 等可选模块，也保存专注时段本身的规则，包括防止提前结束的专注时段保护和停止条件。

计划管理

从启动器，变成真正的工作习惯。

计划让预设从按钮变成日常规则。例如工作日 09:00 启动“编程”，18:00 结束后交给“休息”。第二个预设可以启动另一组应用，使用不同的屏蔽规则。

计划属于工作区定义的一部分，无需单独编写任务计划程序脚本，再与屏蔽设置保持同步。

专注时段保护

决定中途退出专注时段的难易程度。

有些专注时段只需要安排，有些则需要更强的约束。Axorith 将结束方式、是否允许休息及完成后的操作一并保存在预设中。

Home Assistant

房间中的设备也能随工作区切换。

Home Assistant 模块可在专注时段开始或结束时触发已配置的实体，让桌灯或场景随数字工作区同步切换，而 Axorith 的其他功能仍在本地运行。

WINDOWS 版 AXORITH

直接启动环境，不必从头搭建。

工作区只需创建一次，之后手动启动或交给计划执行。
