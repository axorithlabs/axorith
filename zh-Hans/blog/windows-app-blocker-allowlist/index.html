应用屏蔽

如何在 Windows 上只允许运行工作应用

先确定工作真正需要哪些应用，而不是试图列出每一种可能分散注意力的程序。

下载 Windows 版GitHub

普通黑名单要求你预先找出所有干扰来源。白名单则反过来：先确定完成任务需要的软件，再限制其他程序。它适合工具明确、但难以预测下一次分心会来自哪里的工作。

先列出真正需要的软件

创建“编程”预设，在 Application Launcher 中加入编辑器、项目和工作浏览器。别忘了终端、密码管理器或必要的通信工具。遗漏这些程序的严格白名单可能妨碍工作，而不是帮助专注。

通过 App Blocker 应用规则

App Blocker 可以只允许当前 Workspace 中配置的应用。将启动器和屏蔽器放进同一个预设，工作环境和限制便能随专注时段一起启动。这是针对特定工作专注时段的设置，并非永久修改 Windows。

启用严格模式前先测试

先运行一个容易停止的短专注时段，检查文件选择器、构建工具、重要消息和辅助功能软件。确认所有必需程序可用，再提高 Focus Commitment 的严格程度。不要阻断重要的安全操作或恢复途径。

什么时候黑名单更合适

如果工作经常需要临时打开未知程序，白名单可能太严格。此时只屏蔽游戏或聊天软件等已知干扰即可。应用启动与日程设置可以保持不变，只调整 App Blocker 的策略。
