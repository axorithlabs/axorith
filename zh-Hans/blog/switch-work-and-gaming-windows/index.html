工作环境切换

如何在 Windows 上切换工作和游戏环境

工作与休闲不必共用同一组窗口、通知和限制。

下载 Windows 版GitHub

同一台电脑很容易混用环境：工作时游戏启动器与 Discord 还开着，休息时 IDE 和项目窗口又挡在眼前。独立预设能够明确每个环境应该是什么样子，减少手动整理。

为不同情境建立独立预设

在“编程”预设中加入 IDE、浏览器和工作屏蔽规则；在“休闲”预设中加入游戏、聊天和音乐，不使用工作限制。不要把所有程序都复制到两个预设里，否则就失去了切换的意义。

选择切换方式

Axorith 可以手动启动预设、按日程启动，或在前一个预设结束后启动。比如工作到指定时间，再切换到休闲。如果每天的安排不固定，手动切换可能比突然自动转换更合适。

不要依赖工具替你保存工作

切换环境不能代替保存文件、提交代码或安全结束重要进程。先用非关键程序测试 Application Launcher 的生命周期选项。预设无法判断未保存的内容是否可以丢弃。

把结束工作变成清晰的边界

两个预设的价值在于清楚地区分工作与休息。工作专注时段结束后，无须逐一手动关闭每项屏蔽就能进入休闲。如果计划有变，修改日程或手动切换即可。
