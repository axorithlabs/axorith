学习流程

如何在 Windows 上安排少干扰的学习专注时段

保留完成作业需要的工具，减少无关内容的干扰。

下载 Windows 版GitHub

学习可能需要 PDF、笔记、浏览器、计算器或视频课程。因此一开始就屏蔽整个互联网通常并不合理。更好的方法是区分学习资源和无关浏览，并设定现实可行的学习时间。

准备当前作业需要的环境

建立“学习”预设，加入笔记应用、参考资料和浏览器。如果作业需要学校网站，确保该网站能打开。准备好实际材料，比启动一个没有学习内容的空泛“学习模式”更有用。

屏蔽娱乐而不是课程

使用 Site Blocker 限制无关社交、购物及娱乐网站，App Blocker 则处理桌面干扰。注意课程服务是否与被屏蔽的网站类别重合。提前收紧规则范围，比上课途中突然打不开网页好得多。

选择能够完成的时长

根据作业设定专注时段时间，并考虑是否需要休息。Focus Commitment 可随预设配置，但并非必须使用严格模式。最好从短专注时段开始，确保学习材料始终可用。

复盘真正的中断原因

结束后检查问题来自被屏蔽的资源、遗漏的文件，还是无关程序。先修正预设，不要默认增加限制。目标是减少准备时间，把精力留给学习本身。
