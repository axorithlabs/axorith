Windows 专注环境

屏蔽应用和网站，再启动 Windows 工作环境

一个预设既去除干扰，也搭建替代它们的工作区。

下载 Windows 版 GitHub

Axorith 将通常分散在不同 Windows 工具中的三件事结合起来：屏蔽桌面应用、屏蔽网站，以及启动真正需要的应用或项目。设置都在一个预设中，让开工变成一次操作。

优先在本地运行，目前围绕 Windows 桌面设计。根据 BSL 1.1 许可，个人及非商业使用免费。

问题

屏蔽只是工作流程的一半。

专注前往往要完成多个独立操作：关闭 Discord 或 Steam、打开 IDE、正确的浏览器配置或项目、播放音乐，再启用网站屏蔽。屏蔽工具能去除干扰，却通常不会搭建替代它们的工作环境。

Axorith 将整个环境视为一个专注时段。预设同时定义哪些内容保持可用，哪些应在专注时段期间消失。

一个预设

同时启动工作区并应用限制。

01

打开工作应用

专注时段开始时启动应用、IDE 项目和浏览器配置。

02

屏蔽桌面干扰

屏蔽选定应用，或仅允许当前工作区中配置的应用。

03

屏蔽干扰网站

专注时段期间应用网站规则和类别屏蔽。

04

按你的规则结束

手动停止、在指定时长后或指定时间结束，或者衔接另一个预设。

应用启动器

打开让专注时间更有价值的工具。

应用启动模块可作为预设的一部分打开应用和 IDE 项目，也支持窗口与生命周期设置，不只是“打开这个 EXE”。目标是在移除干扰的同时，准备好需要的工作环境。

定时运行

手动启动，或按指定时间运行。

预设可手动或按计划运行。例如周一至周五 09:00 开始，在指定时间或经过一定时长后停止，再启动“休息”等另一个预设。

这就是一组独立工具与统一工作区规则的区别：启动、屏蔽和结束条件共享同一个专注时段生命周期。

适用范围

Axorith 不打算替代什么。

Axorith 目前面向 Windows 桌面。如果主要需求是在手机、平板和电脑间同步屏蔽，Freedom 这类跨设备产品更合适。Axorith 关注工作区本身：启动什么、屏蔽什么、专注时段持续多久、结束后做什么。

WINDOWS 版 AXORITH

直接启动环境，不必从头搭建。

工作区只需创建一次，之后手动启动或交给计划执行。
