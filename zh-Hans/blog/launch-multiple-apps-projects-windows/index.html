应用启动器

如何在 Windows 上同时启动工作应用和项目

偶尔打开一组工具很简单；每天重复同样的步骤才浪费时间。

下载 Windows 版GitHub

工作日可能总要打开相同的编辑器、仓库、浏览器和辅助程序。启动器能减少这些点击。Axorith 还将启动流程存放在预设中，并可同时配置干扰屏蔽和专注时段时长。

列出属于同一任务的工具

先从 IDE、项目、浏览器开始，必要时再加终端或笔记。不要为了“以防万一”打开一大堆程序。好的预设应让接下来的任务更清楚，而不是把桌面堆满窗口。

通过 Application Launcher 进行配置

该模块可启动应用和 IDE 项目，并提供窗口位置与生命周期选项。把这些设置放进预设，与其他模块一起启动。移动仓库或重新安装软件之后要检查路径；错误路径会导致启动失败。

只在需要时添加屏蔽

同一预设可以包含 App Blocker 与 Site Blocker，但不是每种工作都需要。研究任务可能适合较自由的环境，写作则可能需要限制游戏和社交网站。没必要让所有工作环境都变成严格锁定的专注时段。

追求可重复而不是复杂

测试预设后，可以手动运行或按日程启动。遇到问题先修正具体原因，不要马上增加更多自动动作。真正的价值在于每天都能可靠地进入工作状态。
