隐私

遥测与数据

Axorith 使用 PostHog 分析网站，并提供可选的桌面产品遥测。网站与桌面应用采用独立访客身份。

网站分析

访问 axorith.com 时，PostHog Web SDK 记录页面浏览与离开、访问会话、Web Vitals、来源类别，以及验证过的 UTM 来源、媒介和活动标签。页面归为首页、模块、隐私等固定类别。发送前移除完整页面和来源 URL、域名、广告点击 ID、UTM 内容与搜索词。还会记录下载和 GitHub 链接点击。下载点击包含按钮位置和 Windows 平台，只有网站确知版本时才包含发行版本。PostHog 可能根据网络元数据推断大致位置。 还会记录所选页面语言。

网站使用 PostHog 的浏览器身份。Axorith 不通过 IP 地址、user-agent 匹配、指纹识别或其他启发式方式将网站访客与之后的安装关联。

桌面遥测

使用遥测默认开启，可在应用的隐私设置中关闭。Client 与 Host 共享该设置。更新读取已保存的选择，新安装保持现有默认值。

启用后，桌面应用发送 Axorith 与系统版本、应用生命周期事件、预设和模块 ID 及内置模块类型、会话 ID 与生命周期、保护和休息设置、计划变更、修改的设置类别、更新和安装结果及结构化错误详情。在 Windows 上，应用、安装程序与卸载程序共享 Windows 提供的假名设备标识。Axorith 不将其存入文件。它在应用重装或删除应用文件夹后仍然保留；根据 Windows 身份来源，也可能在全新安装 Windows 后保留。更新时若旧身份可用，迁移事件会包含新旧标识以关联遥测。

错误事件包含异常类型、稳定指纹、子系统、操作、严重程度、已处理或致命状态，以及数量受限且经过清理的方法名。重复错误会被限频并汇总。

桌面应用不发送的信息

桌面遥测不包含预设名称、自定义模块或操作名称、设置值、文件或可执行文件路径、进程名称、命令行参数、URL、域名、Home Assistant 实体 ID、访问令牌、机密信息、原始异常消息或完整堆栈跟踪。Axorith 不会将 IP 地址作为事件属性发送。PostHog 可能根据网络元数据推断大致位置。

PostHog 与身份

网站和桌面事件发送到同一个 Axorith PostHog 项目，但采用独立身份。网站不使用桌面应用的设备标识。
