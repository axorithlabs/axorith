Powerful Modules

Everything you need to automate your digital life. Each module is designed to integrate seamlessly with your workflow.

🛡️ Focus & Productivity

Block distractions and stay in the zone

App Blocker

Block distracting applications from running during focus sessions. Supports category blocking for games, social apps, and browsers.

  • Category blocking (Games, Social, Browsers)
  • Custom blocklist
  • Real-time monitoring

Site Blocker

Block distracting websites via browser extension. Works even when the UI is closed thanks to native messaging.

  • Block list or Allow list mode
  • Firefox & Chrome support
  • Works in background

🚀 Application Launchers

Launch and control your favorite applications

Browser

Launch any browser with advanced options. Supports Chrome, Firefox, Edge, Brave, Opera, and many more.

  • Auto-detect installed browsers
  • Profile selection
  • Incognito mode

VS Code

Launch Visual Studio Code with a specific project. Perfect for developers who want instant workspace setup.

  • Auto-detect installation
  • Project path selection
  • Custom launch arguments

JetBrains IDE

Launch any JetBrains IDE with a project. Supports IntelliJ, PyCharm, WebStorm, Rider, and all other IDEs.

  • Toolbox integration
  • All JetBrains IDEs
  • Extended startup timeout

Discord

Launch and manage Discord. Waits for full load, skipping splash screens and update checks.

  • Auto-detect installation
  • Smart loading detection
  • Skip splash screens

Steam

Launch Steam and optionally start a game directly. Auto-scans your library for installed games.

  • Game library scanning
  • Direct game launch
  • Steam protocol support

Spotify

Launch Spotify with full playback control. Auto-play playlists, set volume, and control shuffle/repeat.

  • OAuth authentication
  • Playback control
  • Device selection

🏠 Smart Home & Streaming

Control your environment beyond the desktop

Home Assistant

Control smart home devices on session start/end. Trigger scenes, scripts, lights, and switches automatically.

  • Long-lived token auth
  • Scenes & scripts
  • Lights & switches

OBS Studio

Launch OBS with WebSocket control. Auto-start streaming or recording when your session begins.

  • WebSocket integration
  • Auto-start streaming
  • Virtual camera control
