Работа по расписанию в Windows

Запуск приложений и блокировка отвлечений по расписанию в Windows

Одно расписание для всего рабочего сеанса вместо отдельных задач для запуска приложений и блокировщиков.

Скачать для Windows GitHub

Планировщик Windows запускает программу в указанное время. Блокировщик ограничивает доступ к отвлекающим приложениям и сайтам. Axorith объединяет эти действия в рабочее пространство по расписанию: запуск, приложения, блокировка и завершение относятся к одному сеансу.

Пример

Начало программирования в 09:00, завершение в 18:00.

09:00Программирование начинается

Запустите IDE и браузер, включите блокировку приложений и сайтов и примените настроенные правила сеанса.

18:00Программирование завершается

Завершите сеанс в указанное время и при необходимости запустите следующий пресет.

Повторяющийся запуск

Привяжите расписание к пресету.

Повторяющийся запуск можно ограничить выбранными днями — например, с понедельника по пятницу. Расписание определяет начало работы всего окружения, а не одного EXE.

Правила завершения

Завершайте сеанс в заданное время или по истечении указанной длительности.

Для постоянного распорядка задайте конкретное время завершения. Если сеанс должен длиться одинаково независимо от времени запуска, укажите его длительность. Пресет также может запускать следующее рабочее пространство после штатного завершения.

Почему недостаточно планировщика задач?

Планировщик задач запускает процесс, но не управляет состоянием рабочего пространства.

Планировщик Windows удобен для задачи «запустить этот файл». Поддерживать распорядок сложнее, когда нужны блокировщики, несколько приложений, пути проектов, защита сеанса и переход к следующему окружению. Axorith объединяет их в пресете вместо набора скриптов и утилит.
