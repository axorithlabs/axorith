Скачайте Axorith.

Один локальный пресет может запускать нужные приложения, блокировать ненужные программы и сайты и работать по расписанию.

Скачать axorith-setup.exe Примечания к выпуску

Исходный код доступен по BSL 1.1. Бесплатно для личного и некоммерческого использования.

01

Локальная служба

Логика сеанса Axorith работает на вашем компьютере Windows. Интерфейс и фоновая служба Host разделены, поэтому активный сеанс не зависит от открытого окна.

02

Прямая загрузка установщика

Кнопка скачивает последнюю версию установщика для Windows из официального релиза на GitHub. Для скачивания не нужны адрес электронной почты и учётная запись.

03

Исходный код доступен

Репозиторий открыт: в нём есть настольное приложение, модули и установщик. Перед установкой можно изучить код и лицензию BSL 1.1.
