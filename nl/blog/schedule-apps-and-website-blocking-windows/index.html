Windows-planning

Plan het starten van apps en blokkeren van afleiding op Windows

Eén schema voor de hele sessie in plaats van aparte taken voor starters en blokkeerders.

Downloaden voor Windows GitHub

Windows Taakplanner start een programma op een tijdstip. Een blokkeerder beperkt afleidende apps en sites. Axorith combineert dit in één geplande werkruimte waarin starttijd, starters, blokkeringen en stopregel bij dezelfde sessie horen.

Voorbeeld

Start Programmeren om 09:00 en stop om 18:00.

09:00Programmeren begint

Start IDE en browser, pas app- en siteblokkering toe en activeer de ingestelde sessieregels.

18:00Programmeren eindigt

Beëindig de sessie op de vaste tijd en start eventueel het volgende profiel.

Terugkerende starts

Koppel het schema aan het profiel.

Terugkerende starts kun je beperken tot dagen zoals maandag tot vrijdag. Het schema bepaalt zo wanneer de hele werkruimte begint, niet alleen wanneer een EXE start.

Stopregels

Stop op tijd of na een duur.

Gebruik een vaste stoptijd voor een vaste routine. Gebruik een duur als de sessie even lang moet zijn ongeacht de starttijd. Het profiel kan na natuurlijke voltooiing de volgende werkruimte starten.

Waarom niet alleen Taakplanner?

Taakplanner start een proces, maar beheert niet de toestand van de werkruimte.

De Windows-planner is handig om een programma uit te voeren. Onderhoud wordt lastiger met blokkeringen, meerdere apps, projectpaden, sessiebeveiliging en een vervolgactie. Axorith bundelt dit in één profiel in plaats van verspreide scripts en tools.
